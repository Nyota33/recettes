# Recettes

Here I publish my recipes as Markdown files, and [python-recettes](https://github.com/leplatrem/python-recettes/) turns them into [this recipes website](https://leplatrem.github.io/recettes/).

## Create your own website

To create your own recipe website, [fork this repository](https://docs.github.com/articles/fork-a-repo) and replace the recipe files in `recipes/` with your own.
