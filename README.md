# Recettes

Here I publish my recipes as Markdown files, and [python-recettes](https://github.com/leplatrem/python-recettes/) turns them into [this recipes website](https://nyota33.github.io/recettes/).

## Contribute

To add suggestions or fixes, just edit the `.md` files and submit a pull-request. To submit new recipes, create a new file following the format of the existing ones.

## Create your own website

To create your own recipe website, [fork this repository](https://docs.github.com/articles/fork-a-repo) and replace the recipes files in `recipes/` with your own.
