# Préparation

## Étape 1

*Préparer le sirop* : dans une casserole, verser 100g de sucre (sur {{ 310g de sucre }}), {{ 17cl d'eau }} et les graines d'une gousse sur {{ 2 gousses de vanille }}. *Porter à ébullition* puis laisser refroidir.

## Étape 2

*Lisser* {{ 170g de beurre tempéré }} avec le reste du sucre (210g) à la spatule. Ajouter {{ 50g de poudre d'amande }}, les graines de la deuxième gousse, puis progressivement {{ 3 oeufs }} et {{ 6cl de lait }}.

## Étape 3

*Tamiser* {{ 240g de farine }} avec {{ 6g de levure chimique }} (1/2 sachet) et les incorporer. Ajouter {{ 90g de noix de pécan }} *hachées grossièrement*.

## Étape 4

*Cuire* 1h à **160ºC**. Laisser refroidir 15min avant de démouler.

## Étape 5

*Imbiber* le cake encore chaud de sirop.
