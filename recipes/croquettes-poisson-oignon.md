# Préparation

## Étape 1

*Tremper* {{ 40g de pain de mie }} émietté dans {{ 30g de lait }} 5min.

## Étape 2

Mettre {{ 80g d'oignon }} dans le bol et *mixer* **5 sec/vitesse 5**. Ajouter le pain, {{ 1 jaune d'oeuf }}, {{ 1 bouquet de ciboulette }} en tronçons, {{ sel }} et {{ poivre }}. *Mixer* **10 sec/vitesse 5**.

## Étape 3

Ajouter {{ 350g de filet de poisson cuit }} émietté et *mixer* **5 sec/vitesse 5**.

## Étape 4

*Former* une douzaine de boulettes, les *paner* dans {{ 1 oeuf }} battu puis dans {{ 40g de chapelure }} poivrée.

## Étape 5

*Dorer* 5 à 6min à la poêle dans de l'{{ huile d'olive }}.

# Conseils

- Chapelure maison : mixer du pain sec **20 sec/vitesse 7**.
