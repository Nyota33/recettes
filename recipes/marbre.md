# Préparation

## Étape 1

*Fouetter* {{ 3 oeufs }} avec {{ 125g de sucre }} jusqu'à blanchiment. Ajouter {{ 125g de beurre }} fondu, puis {{ 125g de farine }} tamisée avec {{ 1 sachet de levure chimique }}.

## Étape 2

*Diviser la pâte* en deux. Dans l'une, ajouter {{ 70g de chocolat }} fondu bien lisse ; dans l'autre, {{ 1 gousse de vanille }} (ou 1 sachet de sucre vanillé).

## Étape 3

Ajouter {{ 10cl de lait }} petit à petit dans chacune pour que les deux pâtes aient la même consistance, sans être trop liquides.

## Étape 4

*Cuire* environ 30min à **180ºC** (th. 6), jusqu'à ce que la lame d'un couteau ressorte sèche.
