# Préparation

## Étape 1

*Fondre* {{ 200g de chocolat noir }} avec {{ 130g de beurre }}.

## Étape 2

Ajouter {{ 10g de sucre }}, puis {{ 4 oeufs }} un par un en mélangeant entre chaque. Incorporer {{ 2 cas bombées de farine }}.

## Étape 3

*Concasser* grossièrement des {{ noix, noisettes, cacahuètes ou amandes }} et les mélanger à la pâte.

## Étape 4

Verser dans un moule beurré (pas trop épais). *Cuire* environ 10min à **200ºC** (th. 6-7), four préchauffé : le gâteau est cuit quand le dessus se crevasse.

# Conseils

La farine n'apparaît pas dans les étapes d'origine ; l'ajouter avec les oeufs. 10g de sucre semble peu (sans doute 100g).
