# Préparation

## Étape 1

Mettre {{ 500g de saucisses fumées précuites }} dans le panier et {{ 1L d'eau }} dans le bol. *Cuire* **12 min/Varoma/vitesse 4**. Vider le bol.

## Étape 2

*Mixer* {{ 10g de gingembre frais }}, {{ 200g d'oignons }} et {{ 2 gousses d'ail }} **5 sec/vitesse 5**. Ajouter {{ 2 cas d'huile d'olive }} et *rissoler* **5 min/120ºC/vitesse 1**.

Pendant ce temps, *couper* les saucisses en tronçons de 3 cm.

## Étape 3

Ajouter {{ 5 tomates }} (550g) et {{ 60g de concentré de tomate }}, *mixer* **3 sec/vitesse 5**.

## Étape 4

Insérer le fouet. Ajouter {{ 1 cas de sucre }}, {{ 1 cas de curcuma }}, {{ 3 brins de thym }} effeuillés, {{ 1 pincée de piment }} et les saucisses. *Cuire* **15 min/100ºC/sens inverse/vitesse mijotage**.

Pendant ce temps, *cuire* {{ 250g de riz basmati }} à l'eau bouillante salée.

## Étape 5

Assaisonner de {{ poivre }} et de {{ sel }}, servir avec le riz.
